# PNC:AA-FO-30 — Blank form reference (manual fill)

Official source: **PNC:AA-FO-30 rev.1 09022025**  
Student Internship Daily Time Record (DTR) Form — Pamantasan ng Cabuyao / Academic Affairs

## Product rule (INTERNTRACK)

In the live app, **FO-30 is a manual form**: students fill it **offline** (paper or this printable blank), then **upload** the completed file (portfolio appendix `dtr_form`).  
INTERNTRACK does **not** ship a digital FO-30 form filler inside Attendance. Attendance remains **Clock In / Clock Out**.

| File | Purpose |

| `PNC-AA-FO-30-official-source.pdf` | Original PDF reference |

## How to use (offline)

1. Open the HTML or official PDF and print, **or** fill fields offline.
2. Sign as required on the paper/PDF form.
3. Upload the completed FO-30 in **Portfolio → Appendices** (`dtr_form`).

FO-31 Daily Journal remains a separate **weekly** manual upload in the student **Logbook**.
