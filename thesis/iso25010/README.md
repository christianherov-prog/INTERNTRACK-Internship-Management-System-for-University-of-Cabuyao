# ISO/IEC 25010 evaluation (Objectives 2 & 3)

External research package for INTERNTRACK — **not** an in-app module.

## Purpose

Evaluate the implemented system against ISO/IEC 25010 product quality characteristics using:

1. **End-user instrument** — students, faculty, coordinators, supervisors, directors who used the portals
2. **IT expert instrument** — faculty advisers / IT practitioners reviewing architecture and quality

## Suggested procedure

1. Obtain adviser clearance / ethics note as required by your college.
2. Copy items into Google Forms, printed Likert sheets, or MS Forms.
3. Target respondents (adjust with adviser): e.g. ≥30 end users across roles; ≥5 IT experts.
4. Scale: **1 = Strongly Disagree … 5 = Strongly Agree**.
5. Compute mean (and SD) per item and per characteristic using [`scoring_sheet.md`](scoring_sheet.md).
6. Paste results into [`analysis_template.md`](analysis_template.md) for Chapter 4/5.
